# Cube Timer

A speedcubing timer that runs in the browser. It's a single HTML file with no build step and no dependencies.

## Features

- **Hold-to-start timing:** hold Space (or touch and hold on a phone) until the time turns green, release to start, then press any key to stop.
- **Scrambles** for 2x2, 3x3 and 4x4, with a colored preview of the scrambled cube for 2x2 and 3x3.
- **Optional 15-second inspection:** starting after 15 seconds adds +2, and after 17 seconds it's a DNF.
- **Statistics:** best, mean, and averages of 5, 12, 50 and 100, trimmed the way official competitions do.
- **Solve list:** mark solves +2 or DNF, delete them, or copy everything as CSV.
- **Animated background:** an anime-style landscape drawn in code. It shows daytime in light mode and dusk with fireflies in dark mode, and can be turned off.
- Solves are saved in your browser's local storage, separately for each puzzle.

## Run it

Open `index.html` in any modern browser, or visit the GitHub Pages link for this repository.
